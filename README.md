# 🎓 MP Events Hub — Backend-микросервис
Микросервис на FastAPI для платформы внеучебной деятельности Московского Политеха. Обеспечивает бэкенд-логику для работы с событиями, пользователями и регистрациями.

# 📌 О проекте
mpu-events — это часть большой экосистемы «Афиша Московского Политеха». Платформа решает проблему разрозненности информации о внеучебных мероприятиях.

## Проблема
Сейчас анонсы событий разбросаны по соцсетям и чатам. Основной канал — группа ВКонтакте — не имеет фильтрации по интересам или датам, а его популярность среди студентов падает. Это приводит к низкой посещаемости и требует от организаторов ручного продвижения каждого события.

## Решение
Единая цифровая платформа, которая предлагает:
* Централизованную афишу всех внеучебных мероприятий

* Удобный поиск и фильтрацию по категориям, датам, форматам

* Персонализированную ленту событий

* Прозрачную систему мотивации и геймификации

* Интерактивные элементы (запись, отмена, напоминания)

# 🏗 Архитектура системы
Платформа разрабатывается несколькими командами:

| Команда | Стек | Ответственность |
|:--------|:-----|:----------------|
| **Бэкенд** | Python/FastAPI | Микросервисы (mp-events-hub) |
| **Фронтенд** | HTML/CSS/JS | Динамический веб-интерфейс |
| **Дизайн** | Figma/Photoshop | UI/UX макеты |
| **Базы данных** | PostgreSQL | Проектирование и поддержка схем |

mpu-events — один из бэкенд-микросервисов, отвечающий за:

- Управление событиями (CRUD)

- Регистрацию пользователей на мероприятия

- Аутентификацию и авторизацию

- Бизнес-логику записи и отмены

# 🛠 Стек технологий
- Python 3.11+ — основной язык

- FastAPI — REST API фреймворк

- PostgreSQL — база данных

- SQLAlchemy 2.0 — ORM

- Alembic — миграции

- Docker — контейнеризация

- Pytest — тестирование

- JWT — аутентификация
